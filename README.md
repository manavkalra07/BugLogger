# BugLogger

BugLogger is a bug tracking system that helps teams report, manage, and track software issues efficiently.

## Features

* User Registration
* User Login
* Password Hashing using bcrypt
* Organization Management
* Dashboard API

## Tech Stack

* Node.js
* Express.js
* MySQL
* bcrypt
* Git & GitHub

## API Endpoints

### User Registration

POST /api/users

### User Login

POST /api/auth/login

### Dashboard

GET /api/dashboard

## Project Status

Current MVP includes:

* User Registration
* User Authentication
* Dashboard

Upcoming Features:

* Create Bug
* View Bugs
* Update Bug Status
* Dashboard Statistics
